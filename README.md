# GEMINI CLI를 이용한 운영툴 자동 생성 프로젝트
## 목적
- gemini-cli를 이용해 <b>무료</b>로 프로젝트 생성
- 과연 실무에 쓸만한지에 대한 테스트

## 프로젝트 시작 전 필요 파일
- GEMINI.md : 제미나이 세팅용 파일
- doc/dir.md : 디렉토리 정의 파일
- doc/notation.md : 코드 작성 규칙 파일
- doc/spec.md : 프로젝트 spec 에 관한 파일
- doc/task.md : 작업 규칙에 관한 파일
- gemini_tasks/task.txt - 세부 작업 내용 파일

## 설치
- windows / linux / macos 모두 설치 가능
- node.js 22 이상 설치 (https://nodejs.org/ko/download)
- node 설치후 npm을 이용해 gemini-cli 설치 (npm install -g @google/gemini-cli)
